วิธีการใช้งานระบบเบื้องต้น
1. เชื่อมกับ node.js + php admin + xampp version 3.3.0
2. ทำการเข้าสู่ server โดยการ cd backend เเละ รัน node server.js
3. เริ่มต้นการทดลอง จะเเบ่งออกเป็น 2 ส่วนหลักๆ 1. ส่วนสำหรับการตั้งค่า รวมถึงเเจ้งเตือนของข้อมูล 2. ระบบในการกรอกข้อมูลได้เเก่ dispensing,laser,push out force,damper
4. เเต่ละไฟล์มี format ของข้อมูลที่เเตกต่างกัน ดังนั้นจึงต้องกรอกข้อมูลตามเเต่ละประเภทของข้อมูล
5. โดยข้อมูลทั้งหมดของระบบนี้จะใช้ MySQL version 5.0.93 เเละจะต้องการเชื่อมผ่าน schema.sql
6. สามารถตรวจสอบ format ของโค้ดได้จากการทดลองอาจจะมีพลาดไปบ้าง
